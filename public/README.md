# Drop your portrait here

Rename your portrait image to **`portrait.png`** and place it in this `public/` directory.

- Recommended aspect ratio: **4:5** (e.g. 800×1000)
- PNG or JPG both fine — but the code references `portrait.png`. If you use JPG, edit `src/sections.jsx` and change `src="portrait.png"` to `src="portrait.jpg"`.

If the file is missing the site will show a striped placeholder.
